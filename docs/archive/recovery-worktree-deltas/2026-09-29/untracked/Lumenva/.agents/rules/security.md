# Segurança e preservação

- Nunca exponha, registre, commite ou copie secrets, credenciais, tokens ou dados pessoais reais. Não leia `.env*` sem necessidade autorizada.
- Mudanças em produção, dados reais, credenciais, limites de segurança, recursos pagos ou operações destrutivas exigem autorização explícita do Owner.
- Antes de integração externa, identifique dados enviados, credenciais, custo, falhas e como desativá-la. Não amplie o escopo sem autorização.
- Preserve controles existentes; não contorne permissionamento, hooks ou bloqueios.
