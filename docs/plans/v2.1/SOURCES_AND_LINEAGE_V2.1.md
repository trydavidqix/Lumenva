## Regras de lineage

1. Código e estado atual do GitHub vencem memória histórica.
2. V2.1 é target architecture, não prova de implementação.
3. Itens superseded mantêm lineage histórico, mas não voltam como arquiteturas concorrentes.
4. Ideias externas entram apenas após mapeamento para um owner semântico existente da Lumenva.
5. Nenhum fork/repo externo é base canônica da Lumenva.
