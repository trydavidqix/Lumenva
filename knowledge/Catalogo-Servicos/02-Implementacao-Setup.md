# Implementação / Setup

> Catálogo interno de serviços da Lumenva — não é conteúdo de RAG, não publicar via `knowledge:obsidian:export`.

- Onboarding completo: criação de org, convite de equipe, MFA admin
- Conexão de número(s) WhatsApp via WAHA (setup de sessão, QR, warm-up 7-14 dias supervisionado)
- Configuração de pipeline(s) de vendas com vocabulary customizado por nicho (clínica, imobiliária, infoproduto, e-commerce, serviços)
- Setup de custom_fields por pipeline
- Migração de dados de CRM anterior (import de leads/contatos)
- Configuração de RBAC/equipe e roteamento automático (round-robin)
- Setup de compliance RGPD (SLA, templates de export/anonimização, consentimento granular)
