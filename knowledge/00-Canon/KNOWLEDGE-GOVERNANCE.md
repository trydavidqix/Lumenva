# KNOWLEDGE GOVERNANCE

## 1. The Single Source of Truth
- The `docs/` and `Lumenva-Knowledge/` directories represent the system's brain.
- When code and knowledge conflict, knowledge is updated first to reflect the intent, then code is fixed.

## 2. Immutable Principles
- Core architectural decisions are recorded as ADRs (Architecture Decision Records) and cannot be violated without formal review.

## 3. Knowledge Decay
- Outdated knowledge is dangerous.
- Documentation must be continuously validated against the current state of the system.
