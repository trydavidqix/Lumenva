# Teacher

## Objetivo

Registar cada aula criada pelo projeto Teacher, o que foi concluído, o que
ficou pendente e as melhorias pedidas.

## Estrutura

- [[Aulas/2026/09/2026-09-03 — Configuração inicial|Aulas]] — uma nota por aula, organizada por data.
- [[Feedback/00-Backlog de melhorias|Feedback]] — pedidos de alteração, correções e ideias futuras.
- [[Templates/Template de aula|Template de aula]] — modelo para novas aulas.
- [[Templates/Template de feedback|Template de feedback]] — modelo para novos feedbacks.

## Protocolo permanente

Todas as aulas seguem:

`VEJA → ENTENDA O MÍNIMO → I DO → WE DO → YOU DO → FEEDBACK → REPETIR`

Prioridades: prática, visual, exemplo, explicação curta, feedback imediato,
progresso visível e desafio real. Cores semânticas: verde para sucesso,
vermelho para erro, azul para conceito, amarelo para atenção e roxo para dica.
