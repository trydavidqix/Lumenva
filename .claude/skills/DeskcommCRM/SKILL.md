# Claude adapter do CRM

1. Leia `CLAUDE.md` e, quando útil, `AGENTS.md`.
2. Leia `.agents/skills/DeskcommCRM/SKILL.md` para a doutrina compartilhada do CRM.
3. Leia as `.claude/rules/` aplicáveis ao caminho atual; rules com `paths:` aplicam-se só aos caminhos declarados.
4. Para workflows, carregue `.claude/skills/verify-change`, `.claude/skills/db-migration` ou `.claude/skills/graphify` quando a tarefa corresponder.
5. Para comportamento do produto, consulte a fonte canônica do domínio apontada por `docs/index.md`.

Este adapter só direciona à doutrina compartilhada. Não duplica contratos, regras de domínio nem uma hierarquia universal entre processo e produto.
