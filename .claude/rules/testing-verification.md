# Evidência de validação

Não declare `DONE`, “corrigido”, “seguro”, “publicado” ou “verde” sem evidência recente compatível com o raio de dano. Carregue `.claude/skills/verify-change/SKILL.md` para escolher os gates pertinentes; não execute a matriz completa para qualquer alteração trivial. Relate comandos executados e o resultado observado, e indique o que não foi medido.
